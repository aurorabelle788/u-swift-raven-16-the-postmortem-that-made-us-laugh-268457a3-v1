A two-sentence postmortem of the silliest fatal time an AI coding agent misunderstood what it was asked and wrecked the code it was given.

## Entry

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes one short account — one or two sentences, no more than 400 characters — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```
